# Word Cloud สำหรับกิจกรรมในห้อง

เว็บแอปสร้างก้อนเมฆคำตอบสด ผู้เข้าร่วมสแกน QR หรือพิมพ์รหัส 4 ตัวเพื่อตอบ ไม่เก็บชื่อ
หน้าเว็บอยู่บน **GitHub Pages** ข้อมูลอยู่บน **Firebase (Firestore)** ผู้จัดล็อกอินด้วย Google

มี 4 หน้า: `index.html` (สร้าง/เลือกกิจกรรม) · `host.html` (ก้อนเมฆ ผู้จัด) · `analysis.html` (วิเคราะห์ + รวมคำ) · `join.html` (ผู้เข้าร่วมบนมือถือ)

---

## ลองก่อน (โหมดทดลอง ไม่ต้องตั้ง Firebase)

1. เปิดเทอร์มินัลในโฟลเดอร์นี้ แล้วรัน `python3 -m http.server 8765`
2. เปิด http://localhost:8765 ในเบราว์เซอร์
3. กด "เริ่มกิจกรรม" แล้วเปิดแท็บใหม่ไปที่ลิงก์ `join.html?c=รหัส` เพื่อลองตอบ

โหมดนี้เก็บข้อมูลในเบราว์เซอร์เครื่องเดียว มือถือเครื่องอื่นเข้าร่วมไม่ได้ ใช้ดูหน้าตาและลองฟังก์ชันเท่านั้น

## ติดตั้งใช้งานจริง (ประมาณ 30 นาที)

### ขั้น 1 สร้างโปรเจกต์ Firebase
1. ไปที่ https://console.firebase.google.com แล้วกด "Create a project" ตั้งชื่ออะไรก็ได้
2. ปิด Google Analytics ได้ ไม่จำเป็น
3. ใช้แผนฟรี (Spark) ไม่ต้องใส่บัตร

### ขั้น 2 เปิดการเข้าสู่ระบบ
Build → **Authentication** → Get started → แท็บ Sign-in method เปิด 2 อย่าง
- **Google** (ใช้กับผู้จัด)
- **Anonymous** (ใช้กับผู้เข้าร่วม ไม่ต้องล็อกอินจริง)

### ขั้น 3 สร้างฐานข้อมูล
Build → **Firestore Database** → Create database → เลือกที่ตั้งใกล้ไทย เช่น `asia-southeast1` (สิงคโปร์) → เลือก **Production mode**
ที่ตั้งเปลี่ยนทีหลังไม่ได้

### ขั้น 4 ลงทะเบียนเว็บแอป แล้วเอาค่าตั้งค่ามาใส่
1. Project settings (ไอคอนเฟือง) → Your apps → ไอคอน **`</>`** (Web) → ตั้งชื่อ → Register app
2. คัดลอกค่า `firebaseConfig` (apiKey, authDomain, projectId, appId)
3. เปิดไฟล์ `js/config.js` แก้ `firebase: null` เป็น

```js
firebase: {
  apiKey: "...",
  authDomain: "ชื่อโปรเจกต์.firebaseapp.com",
  projectId: "ชื่อโปรเจกต์",
  appId: "..."
},
hostEmail: "อีเมลgoogleของคุณ@gmail.com"   // ตัวพิมพ์เล็ก
```
ค่าเหล่านี้เปิดเผยในเว็บได้ตามปกติของ Firebase ความปลอดภัยอยู่ที่กฎในขั้น 5

### ขั้น 5 วางกฎความปลอดภัย (สำคัญ)
1. เปิดไฟล์ `firestore.rules` แก้ `YOUR_EMAIL@gmail.com` เป็นอีเมลของคุณ (ตัวพิมพ์เล็ก ตรงกับ `hostEmail`)
2. Firestore Database → แท็บ **Rules** → ลบของเดิม วางเนื้อหาทั้งไฟล์ → **Publish**

กฎนี้ทำให้ผู้เข้าร่วมเขียนคำตอบได้อย่างเดียว (คนละไม่เกิน 5 คำ ปลอมเป็นคนอื่นไม่ได้) อ่านคำตอบดิบไม่ได้ และมีแต่คุณที่ดู ลบ และสร้างกิจกรรมได้

### ขั้น 6 เอาขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub (ตั้งเป็น Public ได้)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ไม่ต้องอัปโหลด `node_modules` ถ้ามี) ผ่านปุ่ม Add file → Upload files
3. Settings → **Pages** → Source: "Deploy from a branch" → Branch: `main` / `/ (root)` → Save
4. รอ 1-2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

### ขั้น 7 อนุญาตโดเมนเว็บของคุณ
Authentication → **Settings** → Authorized domains → Add domain → ใส่ `ชื่อผู้ใช้.github.io`
ถ้าไม่ทำ ปุ่มเข้าสู่ระบบด้วย Google จะขึ้นข้อผิดพลาด `unauthorized-domain`

### ขั้น 8 ทดสอบ (ควรทำก่อนใช้กับนักเรียน)
1. เปิดลิงก์เว็บ → เข้าสู่ระบบด้วย Google → พิมพ์คำถาม → เริ่มกิจกรรม
2. ใช้มือถือสแกน QR บนหน้าก้อนเมฆ (หรือเปิด `join.html` แล้วพิมพ์รหัส) → ส่งคำ 2-3 คำ
3. ดูว่าคำขึ้นบนหน้าก้อนเมฆของผู้จัด และมือถือเห็นก้อนเมฆหลังส่ง (ช้าได้ 2-17 วินาที)
4. ลองส่งออก CSV กับภาพ แล้วลบผล
5. ลองกับนักเรียน 5-10 คนก่อนใช้ทั้งห้อง

## วิธีใช้ในห้อง

1. เปิดเว็บ → เข้าสู่ระบบ → พิมพ์คำถาม → **เริ่มกิจกรรม** (ระบบสร้างรหัส 4 ตัวและ QR ให้)
2. ในหน้าก้อนเมฆ ตั้งค่าก่อนผู้ตอบเข้า เช่น โทนสี จำนวนคำต่อคน หัวข้อข้อมูลผู้ตอบ (ระดับชั้น ห้อง เพศ ฯลฯ ถ้าต้องการ)
3. กด **โหมดนำเสนอ** บนโปรเจกเตอร์ QR กับรหัสอยู่ที่มุมบน ไม่บังก้อนเมฆ กดที่ QR เพื่อขยายให้คนหลังห้องสแกนได้
4. ผู้เข้าร่วมสแกน QR หรือเปิด `…/join.html` แล้วพิมพ์รหัส
5. ระหว่างกิจกรรม: ซ่อนผลจากผู้เข้าร่วม · หยุดแสดงชั่วคราว · กดที่คำเพื่อซ่อน · ปิดรับคำตอบ
6. จบกิจกรรม: ปิดรับ → ไปหน้า **วิเคราะห์** (ตัดสินใจรวมคำ) → **ส่งออก CSV / ภาพ** → **ลบผล**

**ต้องเปิดหน้าก้อนเมฆของผู้จัดค้างไว้ตลอดกิจกรรม** เพราะหน้านั้นเป็นตัวสรุปผลส่งให้ผู้ตอบ ถ้าปิด ผู้ตอบจะส่งคำได้ แต่ก้อนเมฆบนมือถือจะไม่อัปเดต

## ข้อควรรู้

**โควตาแผนฟรี** (ตามหน้าราคา Firebase ที่ผมค้นไว้ ควรเช็กอีกครั้ง) Firestore อ่านได้ 50,000 ครั้งต่อวัน เขียน 20,000 ครั้งต่อวัน
- ผู้เข้าร่วมแต่ละคนดึงผลทุก 15 วินาทีหลังส่ง ประมาณ 4 ครั้งต่อนาที เช่น 500 คน นาน 10 นาที ราว 20,000 ครั้ง จึงควรใช้ไม่เกิน 2 กิจกรรมใหญ่ต่อวัน
- ถ้าเปิด "ซ่อนผลจากผู้เข้าร่วม" ผู้ตอบจะไม่ดึงภาพก้อนเมฆ ช่วยลดการอ่านได้
- ถ้าเกินโควตา บริการจะหยุดจนถึงรอบถัดไป ถ้าจะใช้งานหนัก ค่อยอัปเกรดเป็น Blaze (จ่ายตามใช้ ตั้งวงเงินแจ้งเตือนได้)

**การลบข้อมูล**
- ลบเองได้ที่ปุ่ม "ลบผล…" ในหน้าก้อนเมฆ (ต้องส่งออกก่อน หรือติ๊กยืนยัน) หรือปุ่ม "ลบ" ในหน้าแรก
- ลบอัตโนมัติ: ทุกครั้งที่ผู้จัดเปิดหน้าแรก กิจกรรมที่เก่ากว่า 48 ชั่วโมงจะถูกลบ นี่ไม่ใช่การลบเบื้องหลัง ถ้าไม่เปิดหน้าแรก ข้อมูลจะค้างอยู่ (เสริม: ตั้ง TTL policy ใน Firestore ที่ field `expiresAt` ได้ แต่ต้องปรับโค้ดเพิ่ม)

**ความเป็นส่วนตัว**
- ไม่เก็บชื่อ ระบบใช้รหัสนิรนามของ Firebase Anonymous ต่ออุปกรณ์ ใน CSV แสดงเป็นรหัสสั้น 6 ตัว
- ข้อมูลหัวข้อ (ระดับชั้น ห้อง เพศ) ไม่บังคับกรอก หน้าวิเคราะห์ซ่อนกลุ่มที่มีน้อยกว่า 5 คำตอบ (ปรับได้) เพื่อไม่ให้ระบุตัวคนตอบได้ สำคัญเมื่อใช้ให้ผู้เรียนสะท้อนผู้สอน

**ข้อจำกัด**
- 1 คน = 1 อุปกรณ์/เบราว์เซอร์ ส่งได้ 1-5 คำตามที่ตั้ง กันการส่งซ้ำแบบทั่วไป ไม่ใช่ระบบกันโกง (ล้างข้อมูลเบราว์เซอร์หรือใช้โหมดไม่ระบุตัวตนแล้วส่งใหม่ได้)
- ส่งแล้วแก้คำไม่ได้ ส่งเพิ่มได้ถ้ายังไม่ครบจำนวน
- การตัดคำภาษาไทยยังไม่มี ระบบนับทั้งคำที่พิมพ์เป็นหนึ่งคำ และรวมคำที่คล้ายกันด้วยกฎง่ายๆ (สะกดห่างกัน 1 ตัว / เป็นส่วนหนึ่งของวลี / รายการคำเหมือนที่คุณใส่เอง) เกณฑ์ยังไม่ได้ปรับกับคำตอบจริง จึงให้ตัดสินใจรวมเองเป็นค่าเริ่มต้น
- ฟอนต์ Noto Sans Thai โหลดจาก Google Fonts ถ้าเครื่องไม่มีอินเทอร์เน็ตจะใช้ฟอนต์ไทยของระบบแทน

## แก้ปัญหา

| อาการ | สาเหตุที่น่าจะเป็น | วิธีแก้ |
|---|---|---|
| ขึ้นแถบ "โหมดทดลองในเครื่อง" ทั้งที่ตั้ง Firebase แล้ว | `js/config.js` ยังเป็น `firebase: null` หรือไฟล์ยังไม่ถูกอัปโหลดใหม่ | ตรวจไฟล์บน GitHub แล้วรีเฟรชแบบล้างแคช (Ctrl+Shift+R) |
| `auth/unauthorized-domain` | ยังไม่ได้เพิ่มโดเมน | ทำขั้น 7 |
| `auth/operation-not-allowed` | ยังไม่ได้เปิด Google หรือ Anonymous | ทำขั้น 2 |
| "บัญชี … ไม่ใช่บัญชีผู้จัด" | `hostEmail` ไม่ตรงกับอีเมลที่ล็อกอิน | แก้ `js/config.js` และ `firestore.rules` ให้ตรงกัน |
| `permission-denied` ตอนผู้จัดสร้างกิจกรรม | ยังไม่ได้ Publish กฎ หรืออีเมลในกฎไม่ตรง | ทำขั้น 5 ซ้ำ |
| ผู้เข้าร่วมส่งแล้วขึ้น "ส่งไม่สำเร็จ" | ปิดรับคำตอบ / ส่งครบแล้ว / ยังไม่เปิด Anonymous | ตรวจสวิตช์ปิดรับ และขั้น 2 |
| ผู้เข้าร่วมเห็นก้อนเมฆไม่อัปเดต | หน้าก้อนเมฆของผู้จัดถูกปิด | เปิดหน้าก้อนเมฆค้างไว้ |

## สถานะการทดสอบ

- **ทดสอบแล้ว** (เบราว์เซอร์จำลอง ในโหมดทดลอง): สร้างกิจกรรม รหัส 4 ตัว QR ผู้เข้าร่วมส่งคำ (รวมกรณีส่งซ้ำ) หน้าผู้จัดเห็นคำ 200 คำตอบ ตัวเลือกหัวข้อข้อมูล ตัวกรองและการซ่อนกลุ่มเล็ก การรวมคำและผลที่หน้าก้อนเมฆ ส่งออก CSV (ภาษาไทยเปิดใน Excel ได้) และภาพ PNG ลบผล ปิดรับคำตอบ รหัสผิด โหมดนำเสนอ
- **ยังไม่ได้ทดสอบกับ Firebase จริง:** ไม่มีบัญชี Firebase ในการทดสอบ ส่วนที่เชื่อม Firebase (การล็อกอิน กฎความปลอดภัย การเขียน/อ่าน Firestore) เขียนตามเอกสารของ Firebase แต่ยังไม่เคยรันจริง ขั้นตอนที่ 8 ด้านบนคือการทดสอบนั้น ถ้าเจอข้อผิดพลาดให้คัดลอกข้อความ (เปิดคอนโซลของเบราว์เซอร์ด้วย F12) มาให้ผมแก้

## ไฟล์ในโฟลเดอร์

```
index.html  host.html  analysis.html  join.html   หน้าเว็บ 4 หน้า
css/style.css                                      สไตล์
js/config.js                                       ตั้งค่า Firebase และอีเมลผู้จัด (แก้ไฟล์นี้)
js/lib.js  js/db.js                                ฟังก์ชันกลางและชั้นเก็บข้อมูล (Firebase / โหมดทดลอง)
js/host.js  js/analysis.js  js/join.js  js/home.js ตัวควบคุมแต่ละหน้า
vendor/                                            ไลบรารีที่แนบมา (Firebase SDK รวมไฟล์เดียว, ตัวสร้าง QR)
firestore.rules                                    กฎความปลอดภัยของฐานข้อมูล (แก้อีเมล แล้ววางใน Firebase)
src/fb.js  package.json                            ใช้สร้าง vendor/firebase.bundle.js ใหม่ (npm install && npm run build) ปกติไม่ต้องใช้
```
